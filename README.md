# JAY VU. — Bilingual Personal Website

Static HTML/CSS/JS for GitHub Pages at `https://jaytranvu-it.github.io/jayvu/`.

## Deploy
1. Unzip the archive.
2. Upload **the contents of this folder**, not the parent folder, to the root of the `jayvu` repository.
3. In GitHub Settings → Pages, select Deploy from a branch → `main` → `/ (root)`.
4. Open `https://jaytranvu-it.github.io/jayvu/`.

## Structure
- `index.html` redirects to `/en/`.
- `en/` and `vi/` have six pages each, plus three stories each.
- `assets/` contains shared CSS and JS.
- `documents/Tran_Van_Ha_CV.pdf` is the included CV if it was available in this session.

## Review before publishing
- Verify education diploma issuing institution and dates.
- Review autobiographical stories and project results for accuracy and confidentiality.
- Confirm all contact links and CV details.
- Google Fonts requires an internet connection; system fonts are fallbacks.

No build step, framework or paid hosting required.
